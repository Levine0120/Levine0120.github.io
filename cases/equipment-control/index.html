01 / PROJECT OVERVIEW

项目概述

两类界面，
分别服务操作与监测。

这组设计用于焊接、切割等设备。操作界面负责控制与设置，看板负责查看状态与数据，两类界面保持一致的提示方式。

A / CONTROL

操作集中

常用动作、设备状态与设置集中展示。

设备识别参数配置执行反馈
B / DATA

数据分层

先看全部设备，再查看单台设备的数据。

设备总览运行监测历史统计

02 / CONTROL LAYOUT

主控界面

固定操作位置，
减少来回查找。

左侧操作，右侧设置，状态与读数相邻显示。

DESIGN FOCUS

控制与反馈相邻。

运行、暂停与复位集中排列，设备旁显示连接、警告与准备状态。

03 / PARAMETER DESIGN

参数设计

设置分组，
查看与修改分开。

主界面保留常用设置，详细参数在侧边分组展开，避免信息拥挤。

01 / GROUPING

相关设置归组

相关参数放在一起，方便查找与修改。

02 / INPUT

输入有依据

名称、数值与单位相邻，选择项与数值输入明确区分。

03 / MODE

区分查看与编辑

进入编辑模式后才能修改，当前设备始终可见。

HMI VARIATIONS

统一操作方式，
适用于不同界面。

运行、调试与生产设置分开呈现，顶部导航保持固定。

04 / TASK FEEDBACK

任务反馈

选中任务，
核对设备与进度。

左侧选任务，右侧查看设备、加工零件与完成进度。

  1. 01

    先选任务

    按完成状态筛选，突出当前任务。

  2. 02

    再核对设备与零件

    设备、订单与零件信息并列，方便确认。

  3. 03

    看进度，再操作

    查看步骤与完成时间，底部固定开始和暂停按钮。
